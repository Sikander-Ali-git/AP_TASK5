# Capstone Project Planning

## Project Title
Web Application Penetration Testing and Security Assessment of DVWA

## Objectives
- Identify common web application vulnerabilities.
- Demonstrate exploitation in a controlled environment.
- Analyze security risks.
- Recommend mitigation strategies.

## Scope
- SQL Injection
- Stored XSS
- Reflected XSS
- CSRF
- File Inclusion
- Burp Suite Testing
- Security Headers Assessment

## Tools
- Kali Linux
- DVWA
- Burp Suite
- Firefox
- Apache
- MySQL
- GitHub

## Timeline

Phase 1: Planning

Phase 2: Vulnerability Assessment

Phase 3: Exploitation & Evidence Collection

Phase 4: Mitigation

Phase 5: Reporting & Presentation
